物理单摆实验

双击「物理单摆实验.html」即可在浏览器中离线使用。页面、模拟程序和语言资源都已内嵌在 HTML 中。

「物理单摆实验.py」是生成这个网页的源代码，在文件夹中运行 `python 物理单摆实验.py` 即可重新生成同名 HTML 文件。生成脚本只使用 Python 标准库。编辑源代码后，可在生成网页并刷新浏览器后查看改动。

实验记录、卷册内容和模拟进度会自动保存在当前浏览器中。请用同一浏览器从同一位置重新打开 HTML，模拟会停在上次保存的位置，点击「开始 / 继续」可接着运行。

要备份或在另一台电脑继续实验，请在「探究卷册」点击「导出任务报告」。在新版网页中点击「导入 JSON 备份」并选择该文件。导入时如已有实验进度，网页会提示确认替换。

旧版 Python 或 HTML 导出的任务报告也可导入。旧报告包含卷册预测、结论、完成状态和该任务下的实验数据。移动 HTML 文件、更换浏览器或清除浏览器数据前，可先导出任务报告备份。
